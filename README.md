# ETF联接基金交易系统

纯场外 ETF 联接基金申赎的量化信号系统（易方达财富账户），包含每日盘后信号、可视化看板和盘中信号脚本。

## 架构

| 模块 | 作用 |
|---|---|
| `main.py` | 主程序：每日盘后更新数据 → 计算信号 → 生成操作提示单 + 看板 |
| `data_fetcher.py` | 数据采集：ETF场内K线(通达信pytdx) / PE估值·北向(Tushare) / 净值·跌停(AkShare) |
| `tdx_data.py` | 通达信数据源：日K线缓存 + 盘中实时行情 |
| `strategy.py` | 策略引擎：PE择时 / 动量轮动 / 移动止盈止损 / 恐慌监控 / MA20趋势闸门 |
| `portfolio.py` | 持仓管理、仓位计算、操作提示单、信号落库 |
| `dashboard.py` | 可视化看板生成（含盘中信号板块） |
| `intraday_signal.py` | **盘中信号核心逻辑**（共享模块，CLI 与看板复用） |
| `scripts/run_intraday_signal.py` | **盘中信号CLI**（薄封装，见下） |

## 快速开始

```bash
# 首次初始化（建表 + 拉历史数据）
python main.py init

# 每日盘后运行（约6分钟，更新数据 + 信号 + 看板）
python main.py

# 仅生成看板
python main.py dashboard

# 持仓管理
python main.py holdings                 # 查看持仓
python main.py buy 019071 --amount 100000            # 申购
python main.py confirm 019071 --shares 38595.14 --nav 2.6045   # 确认份额
python main.py sell 019071              # 赎回全部
python main.py update 019071 --shares 38595.14 --cost_nav 2.5910  # 修正持仓
```

## 盘中信号脚本（当日决策 → 当日成交）

### 解决什么问题

场外申赎规则：**15:00 前提交 → 按当日收盘净值成交**。而盘后信号依赖当日收盘价，只能收盘后计算，提交后实际按 T+1 的未知净值成交——存在时间差。

利用全部决策规则（动量/MA20/Top3）都**只依赖当日收盘价**的性质：在 **14:40-14:50** 用场内ETF现价当作"今日收盘价代理"计算信号，15:00 前提交，即可做到当日决策 → 当日按收盘净值成交。

盘中现价对收盘的预测误差通常 <0.3%，对动量/MA20/排名这类慢变量完全够用。

### 用法

```bash
# 只看信号 —— 持仓状态每天自动从主系统数据库(portfolio表)读取
python scripts/run_intraday_signal.py

# 仅当数据库无持仓时才需要手动声明（基金代码:买入日期YYYYMMDD，逗号分隔）
python scripts/run_intraday_signal.py --holdings "021893:20260811,019666:20260820"

# 脚本只显示信号、不自动记账；确认在平台提交申赎后，
# 请自行用 main.py buy/confirm/sell 维护持仓系统
```

**已集成到主看板**：同一份盘中信号在 `main.py` / `main.py dashboard` 更新看板时自动计算，显示在"🕐 盘中信号"板块（实时行情、动量排名、申购/赎回/持有建议），无需单独运行。CLI 适合盘中快速查看，看板适合留档回顾。

### 输出示例

```
🟢 申购: 电网设备ETF(025856)    ← 动量Top3 且未持有
🔴 赎回: 电池ETF(012862)、半导体ETF(021893)  ← 跌出Top3 且已过7天锁
⚪ 持有: 黄金ETF(000307)、红利低波ETF(020602)
```

### 关键机制

- **实时行情缩放**：通达信 pytdx 实时报价对 ETF/基金返回 **10倍**值（如黄金ETF报99.41，真实9.941），`tdx_data.get_realtime_quotes()` 用数据库昨收自动校准还原。
- **7天最短持有锁**：持有<7天（自然日）不触发赎回，避免 1.5% 惩罚赎回费。
- **持仓状态每日同步**：每次运行自动从主系统 `portfolio` 表读取持仓与买入日期（买入日期=份额确认日 `confirm_date`，缺失时用申购日），脚本不写任何状态、不自动记账。
- **买入闸门**：与主系统一致——动量Top3 + 综合动量>0 + 收盘价在MA20上方，三者全满足才建议申购。

### 使用注意事项

1. **时效**：必须在 14:40-14:50 跑、14:50 前提交才有意义；收盘后跑只是重复当日已定的结论。
2. **临界信号**：现价对收盘是估计（<0.3% 误差），若某只ETF恰在临界（排名3/4交替、MA20贴线），建议当天不动、等次日确认。
3. **7天锁的简化**：脚本用单一"买入日期"判断持有天数；若近期有加仓，新份额的持有时间更短，赎回前请以最后一笔加仓确认日为准复核。
4. **不自动记账**：脚本只输出信号、不修改任何持仓状态；确认在平台提交申赎后，请自行用 `main.py buy/confirm/sell` 记录到持仓系统。

## 策略规则

### 宽基底仓（60%）
PE百分位择时 + MA120趋势过滤：PE<30%且均线向上→买入，PE>80%或均线向下→减仓。

### 行业卫星（40%）
- **动量轮动**：10日动量×0.6 + 30日动量×0.4 综合排名，持有Top3
- **买入闸门**（三重全满足）：①动量Top3 ②复合动量>0 ③收盘价在MA20上方
- **卖出防线**（任一触发）：①移动止盈（激活8%，回撤6%）②MA20×0.95趋势止损 ③固定止损-15% ④跌出Top3（14天轮动缓冲）

### 恐慌监控
沪深300跌幅/北向流出/跌停家数/成交量放大，≥2项触发收紧止损阈值。

## 数据源

| 数据 | 来源 | 说明 |
|---|---|---|
| ETF场内K线 | 通达信 pytdx | 免费无限流，本地缓存增量更新 |
| PE估值/北向 | Tushare Pro | Token 配置在 `local_secrets.py` |
| 联接基金净值 | AkShare | 东方财富数据源 |
| 跌停统计 | AkShare | 东方财富数据源 |
| 盘中实时行情 | 通达信 pytdx | `get_security_quotes`，ETF 10倍自动校准 |
